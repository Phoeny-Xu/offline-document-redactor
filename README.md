# 法律文书脱敏助手

法律文书脱敏助手是一款在Windows和macOS本机运行的文书检查与脱敏工具，可处理合同、诉讼材料及其他文书。它识别敏感信息，生成可供人工核对的替换建议，并支持文字文书映射还原和PDF本机复核。

**文书处理不连接云端模型。**首次安装依赖需要联网；安装完成后，文书处理不联网。

> **当前版本：v1.3.0。**Windows端已完成既定功能场景的实机验收。Apple芯片Mac已完成实机验收，Intel Mac回归尚未覆盖。

## 主要功能

### 敏感信息识别与全文一致替换

工具可识别人名、企业名称、证件号码、手机号和座机、邮箱、通信地址、银行账号、金额、日期等信息，也可在明确标签和受支持格式下识别代理律师姓名及律师执业编号，并将同一实体在全文中使用一致编号的占位符，例如`[姓名#1]`。识别结果供人工复核，用户可以选择保留不需要替换的内容，也可以补充漏识别的原文和别名。

英文规则覆盖带字段标签的姓名、地址、国际电话、常见公司法定后缀及简称；标题式公司名称中的单个小写品牌词仅按受限结构识别。拼音姓名只在明确的拼音姓名标签下识别；密钥/凭据依赖已知令牌格式或明确键值结构。部分身份/税务编号和银行标识依赖字段标签；这不是通用英文实体识别，自动候选不能证明全文无漏项。外发前请核对并补录未识别内容。

英语诉讼与仲裁文书另支持受控的案号、法院名称、仲裁机构、角色姓名、送达地址及执业编号识别。仲裁机构缩写需有仲裁语境，中文仲裁案号需符合受支持的机构词格式；这类规则不等同于通用英文实体识别，仍须逐项核对。

### 多种文书处理方式

| 格式 | 处理方式 |
| --- | --- |
| Word（DOCX）、TXT、Markdown | 对照原文与脱敏预览，确认替换项后生成脱敏文书；DOCX批注和受支持修订默认保留并脱敏；DOCX外链默认移除，可选择保留并扫描超链接目标中的可识别敏感信息 |
| PDF | 各页尝试本机OCR，文字页保留文字层并补充OCR候选；机器自动处置后重建页面并导出脱敏PDF，移除可点击链接 |

诉讼案号、法院名称和公文/机构编号均作为候选显示；无法仅按格式判断类别的编号候选默认不勾选，由使用者在对照页选择是否脱敏。案件或项目名称可用于保存自选字段，供后续文书复用。规则保存在本机，不会自动同步到其他设备。

每次处理一份文件，单个文件不超过100MB。旧版Word（DOC）请先另存为DOCX。

### PDF自动处置与直出导出

#### 解析风险与复核状态

解析和检查风险默认收起在“无法安全脱敏的内容（点击查看详情）”中；PDF待办未处理时，服务端拒绝导出，阻断原因显示在“导出脱敏 PDF”按钮下方。

#### 自动处置与待办门禁

PDF项目显示原页和导出预览。文字层与OCR候选按位置合并；跨行命中按字符行分别高亮和遮盖，空间不足以放置代号时清除原字而不覆盖相邻正文。实体分表示字段类型判断，OCR分表示文字识别，定位几何决定处理模式，三者分别判断，不合成最低值。定位按逐字符标签局部判断，空格无字形框不计为坐标不完整，一处粗定位不拖累同页精确候选。扫描完成后机器自动处置：能精确改字的候选自动替换；有真实框但不能精确改字的候选自动按框处理，代号放不下则遮盖；实体分低于0.50的候选与编号候选默认不自动处理，列入待办。已检测但未作决定的候选，包括有框未选择项和缺少坐标的命中，都必须自动处理、手工遮盖或明确保留后才能导出。此规则也适用于升级后仍未完成复核的旧PDF项目；风险确认不能越过待办门禁。每个候选提供“自动/遮盖/保留”三态切换。低于0.30展示下限的规则命中按页显示并提示，计数是未去重的命中数；OCR低分、粗定位等原因留在候选项内说明。扫描进度和识别边界按页提示。导出后提示按最终处置状态汇总替换、按框处理、人工遮盖、机器自动处理和保留原文的数量，不把同一候选重复计为已处理和保留。

#### 导出提示与确认

PDF导出按钮前持续显示通用提示：自动识别无法穷尽文书中的全部敏感字段，识别结果也可能有偏差，外发前请人工核对导出的文件。该提示不要求确认、不阻断导出。存在尚未处置的已检测敏感候选时，服务端会拒绝导出，确认参数也不能绕过；必须先处理、遮盖或明确保留。识别失败页未确认、扫描已停止或本次没有任何替换/遮盖等其他风险，仍会在导出前显示一次“我已知悉，仍要导出”提示。一般提示还包括识别失败补充信息、按类型保留的候选、链接移除数量、批注及像素稿说明，不要求逐项操作。导出提示只说明处置结果和可能保留的原文，不显示坐标或几何诊断。PDF页面上印出的网址仍须单独脱敏或遮盖。项目可在服务重启后继续处理或取回原始PDF。

#### PDF导出文件与人工定位

带文字层PDF会按表格单元格和独立栏位分开匹配，单元格内换行按同一字段处理；建议对照导出预览抽查候选处理效果。导出PDF通过重建页面图像完成，不保留文本层，可能无法搜索或复制文字，也会移除可点击链接。PDF不生成JSON格式的映射文件，不能通过映射还原；遮盖不可逆，需要原件时应从本机项目取回。PDF批注及批注人名称可能作为页面内容保留，须逐页检查。

PDF人工定位时会显示目标及“取消本次定位”；切页或明确保留后结束当前定位。未知页码须在实际出现页框选。待办摘要在切页和缩放后保留；修改后须重新核对并确认导出。识别失败页需人工检查当前预览后显式确认。手工矩形遮盖也会覆盖框内普通正文，请对照预览缩小范围；窄窗口会改为纵向排列。

### Word网址、修订与文档结构

#### 网址和外链

可见网址识别覆盖不区分大小写的`http://`、`https://`、`www.`以及`.com`、`.cn`裸域名，并校验网址结构；格式有效的显式网址规则分为0.62，格式异常时进入0.42低实体分候选。裸域名规则分为0.42，低于0.50实体复核线但高于0.30展示下限，默认未勾选，用户核实后可勾选替换。规则分为启发式分数，不是经统计样本校准的正确概率。DOCX默认移除全部外部关系；超链接显示文字保留并按可见网址规则扫描，外链图片或对象可能不再显示。选择保留外部关系时，外部超链接目标中符合规则的敏感内容也进入候选；目标打开后的远端网页内容、其他关系目标和字段指令中的网址不扫描。字段指令可能显示“打开官网”等文字，但其指令中保存的网址仍须在Word中检查。

#### 修订、文本框与图片说明

DOCX受支持修订默认保留并脱敏，工具不会自动接受、拒绝或移除修订。接受/拒绝视图分别扫描，因此拆分在多个文字片段中的候选可按组合后的内容识别。无冒号的“员工”“法人”等普通词不会单独作为强姓名标签；识别候选仍需人工核对。

正文、表格、页眉和页脚中的普通文本框（包括VML/DrawingML结构）、简单未绑定纯文本内容控件及受支持的隐藏文字会纳入扫描、脱敏和映射还原，清理时校验对象结构并保留隐藏格式。符合简单VML文字路径结构的纯文字水印也会扫描、脱敏并纳入mapping。图片/绘图对象的替代文字和标题属性`wp:docPr@descr`、`@title`会作为候选，按选择脱敏并由mapping还原；图片像素文字仍需人工核对。Word兼容备用文本框副本、脚注/尾注正文、字段代码、复杂水印及部分未支持修订可能无法自动脱敏；导出前将相关未处理范围合并为一次知悉确认，最多列出五类实质风险。未支持的修订文字（包括移动修订）会在复核页按位置提示，导出确认说明可能按原文保留；确认后可以继续导出，未处理内容仍可能含敏感信息。低置信候选、按选择保留的字段及移除外链等非阻断信息在导出结果中汇总，不增加导出前确认。完全重合的多类型候选合并为一次写入并列出各类型占位符；连续的部分重叠范围合并后写入，mapping记录全部类型并只还原一次。未处理内容不会进入mapping。自动识别无法穷尽文书中的全部敏感字段，识别结果也可能存在偏差；外发前请人工核对最终文件。损坏的DOCX包、XML无效、写入错位或完整性校验失败仍会阻止导出。

### 旧PDF项目与统一提示

旧版PDF项目如果只保存实体分与OCR分取低值的综合分，升级后会保留并标为旧版综合分，不会推算成实体分或OCR分；旧项目不重新OCR，已有勾选、明确保留和手工遮盖全部保留。仍未作决定的旧项目候选会进入待办，必须处理或明确保留后才能导出。新项目的实体分是规则启发式值，不是经标注样本校准的正确概率。

Word复核页和PDF导出按钮前显示相同的提示：“自动识别无法穷尽文书中的全部敏感字段，识别结果也可能有偏差，外发前请人工核对导出的文件。”其下以灰色小字说明可能未识别的敏感内容会按原文保留；Word确认卡中的具体未扫描项也以灰色小字列出。

## 平台与OCR

### Windows OCR

Windows扫描页默认在独立工作进程中使用RapidOCR，网页服务进程不直接加载OCR原生依赖。OCR启动、通信或单页识别超时时会终止工作进程，本页按识别失败或补充识别失败处理，状态查询和其他页面仍可继续；下一次识别会重建工作进程。服务重启时会恢复原件仍在的未完成PDF项目，无法恢复的项目会标为失败并允许重试。仅在RapidOCR导入阶段触发`ImportError`时才尝试Windows系统OCR。系统OCR要求包内Windows.Foundation、Windows.Foundation.Collections、Windows.Graphics.Imaging、Windows.Media.Ocr、Windows.Storage及Windows.Storage.Streams运行绑定可用，并且Windows用户语言配置已安装相应OCR语言包。缺少运行绑定或语言包时会按本页识别失败处理。RapidOCR模型缺失、初始化或识别运行异常、超时均按本页识别失败处理，不自动切换到系统OCR。macOS扫描页使用随包提供的Apple Vision程序`pdf_vision_ocr`。两平台共用后续候选处理、人工复核和PDF导出门禁，但OCR引擎不同，识别结果不保证相同。

### macOS OCR与识别边界

macOS OCR程序已静态确认包含Intel与Apple芯片架构；Apple芯片Mac已完成实机验收，Intel Mac回归尚未覆盖。OCR可能漏识别或定位不准，印章、签名等图形也不会自动识别。使用者仍须检查全部页面，必要时手工框选。

## 安装与启动

同一个压缩包适用于Windows和macOS。若不想自行安装，可将完整安装包交给WorkBuddy，或其他支持操作本机文件并执行命令的智能体，协助解压和安装；不限定使用WorkBuddy。**文书处理不连接云端模型。**首次安装依赖需要联网；安装完成后，文书处理不联网。请先解压完整的`文书脱敏工具-安装包.zip`，再进入其中的`workbuddy-bundle`目录。

### Windows

（1）双击`install_windows.bat`。安装需要Python3.9或更新版本。

（2）安装完成后，双击桌面上的“法律文书脱敏助手（WorkBuddy）.bat”。

### macOS

（1）在终端进入`workbuddy-bundle`目录，运行`bash install_macos.sh`。安装需要Python3.9或更新版本。

（2）安装完成后，双击桌面上的“法律文书脱敏助手（WorkBuddy）.app”启动；同一目录还会生成“停止法律文书脱敏助手服务.app”用于停止本工具服务。可通过`CONTRACT_DESENSITIZER_SKILLS_DIR`指定技能目录，桌面入口会记录并使用实际目录。

两平台都会在浏览器打开本机网页，服务监听`127.0.0.1:18800`。使用完成后，在网页右上角选择“退出”停止服务。

## 本机资料与隐私

### 文件、映射与处理策略

上传原件、PDF项目资料和文字文书映射文件保存在本机。新上传时金额和日期默认启用；DOCX、TXT和Markdown可在复核页按类型操作，或单处切换候选。PDF复核页不提供跨页金额/日期类型开关和“全部不脱敏”入口；项目已保存的默认状态仍生效，但页面不显示该状态。候选仍可按本页同类批量处理，或逐项选择“自动/遮盖/保留”，旧项目保存状态不自动重置。DOCX等文字文书的JSON格式映射文件仅在脱敏成功且有替换记录时生成；mapping默认不下载，用户主动勾选后须再次确认，成功结果区和历史页的另存入口也会要求确认。映射文件包含被替换的原文，应与原件同等保护，不要与脱敏稿一起发给接收方。PDF不生成映射文件。

### 会话资料清理范围

服务只监听本机地址，但同一设备上的其他程序仍可能访问本机服务和会话资料。不要将服务端口转发或暴露到其他设备。交付、共享或更换设备前，可在“历史记录”中执行“清理全部明文”：工具会按当前规则尝试清理工具数据目录内各会话的上传文书副本、PDF私有缓存、项目状态及符合命名规则的映射、日志和临时文件，已完成的脱敏稿会保留。电脑原位置上的源文件、浏览器下载文件、用户另存文件、案件/项目自选规则及会话目录外的文件不在本次范围；不符合命名规则的映射也可能保留。删除单条记录会尝试删除该记录对应的会话目录，失败时页面会提示错误。

## 已知限制

（1）自动识别不是完整性保证。识别可能漏项或误报；所有候选和页面均须人工检查。

（2）图片像素中的文字不自动识别。DOCX图片/绘图对象的受支持替代文字和标题属性可作为候选复核、脱敏和还原；图片本身随文保留。TXT和Markdown不处理内嵌图片。PDF中的印章、签名和其他图形需要手工框选遮盖。

（3）PDF导出会重建页面图像，不保留原文字层、批注或附件，可能无法搜索和复制。PDF批注和批注人名称可能作为页面内容保留；工具不能单独识别并替换批注人名称，须逐页核对。映射文件不能恢复PDF原件。

（4）Apple芯片Mac已完成实机验收，Intel Mac回归尚未覆盖。自动识别仍可能漏项；正式使用前请用非敏感材料验证安装、识别、复核和导出流程。
